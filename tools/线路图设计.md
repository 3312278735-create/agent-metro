# 线路图设计说明

需求线路图（双击「打开地铁图.bat」看到的那一页）是用户回答「做完了哪些、还剩哪些、现在要我做什么」的地方，也在上面直接改台账。改它的样子之前先读这一页，改完把新定下的东西补进来。

## 五条原则

1. **主次分明**——做完的、归档的省略显示，要盯的醒目显示，不让无用的东西干扰
   - 只有「等你验」（橙）和「在做」（蓝）的站是色块，置顶的站也算要盯的。
   - 没开工、暂缓的站：小灰点 + 小字站名。
   - 做完、停运、归档线上的站：收成轨道上的「⋯ N」，点开才摊开。
2. **不加没用的字**——不写「待你验收·验收期还剩2天·返工2轮」这类状态杂字
   - 站下面只写站名。编号、状态、日期放在鼠标悬停提示和点开的详情面板里。
   - 不写验收期还剩几天、返工几轮这类字。
3. **打开先看到要你做的**（10-08，#T135）
   - 页头下面第一块是「要你做的」：等你验收的站按到点先后排（过期的排最前、标红），默认列 5 件，「还有 N 件」点开看全部。
   - 点一行跳到线上那一站：挡着的折叠、筛选自动让开，那一站闪两下。
4. **一屏放得下，不横着拖**（10-08，#T135）
   - 一条线放不下就折到下一行，不出横向滚动条，不被右边截掉。
   - 全线到站、已归档的线默认只占一行；用户手动点开过的会记住。
5. **页头清爽**（10-08，#T135）
   - 页头只留：标题、「N 件等你验 · N 件在做」、搜索框、「筛选 ▼」。
   - 置顶、状态、范围、线路图 / 列表、一段说明，都收在「筛选」面板里；有筛选条件在起作用时按钮写「筛选 · N」。
   - 「服务有更新、点刷新」这类提醒例外，直接显示在页头下面。

## 界面偏好

1. **色块分区**：每块一种底色。状态色固定：完成绿、待验收橙、在做蓝、未开始 / 暂缓灰；要你动手的区域淡紫；记录类灰；块里的正文放白底框。
2. **扁平**：不要阴影、渐变、胶囊、粗边框；小方框、细边，高度压扁。参照：站点详情里的电池。
3. **颜色递进 = 进度**：越往后颜色越深、整格填满；当前位置用「▼ 现在」箭头标；没走到的白底空格。
4. **越急越显眼**：快到点、过期的更醒目，还远的变淡。
5. **按流程顺序、从左往右**：主线一步步排，岔路（暂缓、停运）单独放；时间轴左远右近。
6. **只放要你动手的**：优先级、记录位置、日期这些留在台账给 AI；同一件事只写一次。
7. **大白话**：「未开始」不叫「未到站」；「完成 · 人工验收 / 自动验收」；数量写「还有 N 项」。
8. **大块能折叠、记住开合**；列表先露 3 项，多的点开。
9. **流水线**：待上线 → 在做（转圈）→ 过了期没处理 / 成品箱。
10. **一条一行**：列表、清单每条一行写完，不要粗标题下面再挂一行小字注释。

## 页面从上到下

1. 页头（标题、两个数、搜索、筛选、刷新）
2. 筛选面板（平时收着）
3. 传送带（#T122，10-10 加）：有到点的站排在带上，从左往右走、越靠右越快到点，最右「到点」筐收过点的（没收尾 / 验收筐 / 审定过期），下面一行排队写预算；倒计时页面自己走、每 30 秒重画；点方块跳到线上那一站。手机宽每格只露一块，多的「+N 站」点开
4. 要你做的
5. 线路分块，每块一种底色：置顶（紫）→ 还有站没到的线路（青）→ 全线到站的线路（绿）→ 已归档线路（灰）。同一父节点的支线（项目页写 `parent: xxx` 的几条线）挂在一张分组卡里。

颜色只用三种状态色：绿 = 到站，橙 = 等你验，蓝 = 在做；其余用灰。深色模式跟着系统走，每种颜色都有深色版。

## 改之前、改完之后

- **大改动先出计划页**：一次要动两处以上界面的，先用 html-plan 出一页计划（每处一张示意图，要用户选的地方给出建议的默认选项），用户回「开做」再改。小改动直接改。
- **改完先自己看图再交**：电脑宽、手机宽（390）、深色各截一张，和改前并排放进一页对照图；按钮、折叠、跳转在后台浏览器里点一遍。没看图不算自测过。
- 只改 `tools/metro-template.html`（样子）和 `tools/build-metro.js`（取数）；写台账的逻辑在 `tools/ledger.js`，不要为了改样子去动它。`metro.html` 是生成出来的，不要手改。

## 给改代码的人

- 本机浏览器里记的查看习惯（记不住也不影响台账）：`metro-filters-v2` 筛选条件，`metro-filters-open-v1` 筛选面板开没开，`metro-folded-v1` 折起的线 / 分块 / 默认折起但手动打开过的线，`metro-fam-collapsed-v1` 父节点收起。
- 「要盯的站」在 `stopHtml()` 里判断（置顶、待验收、进行中）；收成「⋯ N」的规则在 `omitOnTrack()`；默认折起的规则在 `foldByDefault()`。
- 后台截图：Chrome 无窗口模式最窄只有 500，测手机宽要把页面放进 390 宽的 iframe 里截。
